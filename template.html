NuSTAR

We maintain NuSTAR, a STAR-derived mapper for bulk and single-cell RNA-seq, including paired-end alignment, two-pass mapping, and STARsolo workflows.

View on GitHub ↗

NuTRF

NuTRF accelerates Tandem Repeats Finder while preserving its detection model and output formats on the tested inputs.

View on GitHub ↗

NuExpansionHunter

We maintain NuExpansionHunter, an Illumina ExpansionHunter fork for repeat-expansion analysis, including catalog reuse, alignment, seed lookup, and BAM output.

View on GitHub ↗

NuMAFFT speeds up MAFFT’s default multiple-sequence alignment workflow using the fast-mafft v10 implementation.
